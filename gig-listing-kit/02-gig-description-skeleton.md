# 02 · Gig Description Skeleton (standard frame + résumé vs product)

> Goal: a buyer understands in ~30 seconds **what you do, how you deliver, rough price shape, and what you won’t do**.  
> A gig description is a **product page**, not a CV.

---

## 1. Standard skeleton (copy, then replace `[ ]`)

```text
[ONE-LINER]
I help you get [specific deliverable]: you send [assets / brief], I deliver [format + contents].

[WHO IT’S FOR]
- People who already have [draft / assets / idea] and need [polish / build / cleanup]
- People racing a [event / deadline] who want fewer revision loops
- Individuals or small teams who can say what “done” looks like

[WHO IT’S NOT FOR / I DECLINE]
- Totally unclear briefs (“just make it nice”) with no willingness to lock scope
- [Illegal or policy-breaking uses] (e.g. forgery, false advertising, unauthorized access)
- [Homework / exam proxy work / review fraud] — hard no
- Expecting unlimited revisions, rock-bottom price, or “start now, price later”

[WHAT YOU GET]
1. [Main deliverable]: … (format: ____)
2. [Extras]: … (usage notes / source files / exports)
3. [Revisions]: [N] rounds in the price; extras or scope changes billed separately

[HOW WE WORK]
1. You send: use case + assets + deadline + optional references
2. I reply: can I take it, estimated hours, tier, delivery formats
3. You confirm scope + price, then order / pay per platform rules
4. I send first draft → you feedback → revise to agreed rounds → final

[PRICING]
- Basic: [one-line scope] | from $[__]
- Standard: [one-line scope] | $[__]
- Rush: [shorter turnaround] | + $[__] or +[__]% on the matching tier
* Final quote after the brief is clear; complex work is estimated first.

[REVISIONS & ACCEPTANCE]
- Please send revision notes as one numbered list
- New topic / new style / large add-ons = scope change → re-quote
- Done means: [checkable items, e.g. consistent layout, no typos I introduced, correct export size]

[TIMELINE]
- Normal: first draft within [X] business days after scope locked
- Rush: when my calendar allows, within [Y] hours/days (ask before ordering)

[COMMUNICATION]
- Prefer on-platform messages (paper trail)
- I reply [weekday window]; nights/weekends may lag

[DISCLAIMER]
- Independent skill service; results vary with brief clarity and asset quality
- I commit to the deliverable — not to “guaranteed hire / viral / approval”
- Follow platform rules and the law; no fake reviews or deceptive promotion
```

---

## 2. Short paste version (tight character limits)

```text
What: [SKILL] → deliver [file + format]
You prepare: [3 bullet asset list]
Flow: lock scope → confirm price → start → [N] revision rounds → final
Price: Basic / Standard / Rush — details in chat; complex work estimated first
I decline: vague scope, illegal uses, homework/exams, fake reviews, unlimited free edits
Order: after price + deadline confirmed; for rush, ask availability first
```

## 3. Résumé voice vs product voice

| Dimension | ❌ Résumé voice (avoid) | ✅ Product voice (prefer) |
|-----------|-------------------------|---------------------------|
| Opening | “Top grad / FAANG / 10 years…” | “I deliver [file]; you send [assets]” |
| Skills | “Expert in every tool & stack” | “This order delivers: [files], formats [A/B]” |
| Proof | “Worked with famous brands, endless awards” | “Similar checkable jobs: [2–3 scenarios]” |
| Attitude | “Perfectionist, world-class” | “[N] revision rounds; extras billed” |
| Price | “Flexible / depends on vibe” | “Basic / Standard / Rush: scope + price” |
| Boundaries | Missing or “I can do anything” | Explicit decline list |
| Evidence | Empty adjectives | Real (redacted) samples — never fake |
| Outcomes | “Guaranteed hire / #1 ranking” | “Responsible for the file, not uncontrollable outcomes” |
| Tone | “I / myself / senior expert” | Short “you / I” action sentences |
| Close | “Hope you’ll consider joining…” | “I start after scope lock; ask these 3 things first…” |

### Same service, two voices

**Résumé-ish:**  
> Design major, great taste, tons of projects, you’ll love it, price negotiable.

**Product voice:**  
> Presentation polish: send editable deck + page count + deadline. I unify fonts, colors, and alignment; you get an editable source file. Two revision rounds included; extra slides or full template swaps billed separately. No speechwriting. No exam/cheating uses.

## 4. Common description bugs (fix before publish)

1. **Only bragging, no buyer outcome** → add “What you get”
2. **No price shape at all** → at least a starting price or unit (per page / per image)
3. **Fuzzy revision policy** → rounds + what counts as a change
4. **No decline list** → at least 3 hard boundaries
5. **Missing steps** → 1-2-3-4 flow
6. **Over-promising outcomes** → promise the deliverable instead
7. **Fake samples / fake sales** → omit rather than invent

---

## 5. Pre-publish paste check

- [ ] One-liner names the deliverable
- [ ] For / not-for sections present
- [ ] Flow + revision rounds present
- [ ] Price band or pricing unit present
- [ ] No banned promises, no review fraud hints, no exam proxy work
- [ ] Reads like a gig, not a job application
