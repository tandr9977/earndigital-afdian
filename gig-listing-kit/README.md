## How to use (3 steps)

1. Pick **one** skill you can deliver with a clear file / deliverable.
2. Adapt **3 titles** from `01` → drop them into the skeleton in `02` → publish.
3. Keep `03` + your filled `04` table in Notes. When someone messages, change the numbers and send.
