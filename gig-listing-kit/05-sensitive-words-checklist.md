# 05 · Sensitive Words & Compliance Checklist (self-audit)

> **Important**  
> 1. Platform rules change. **Always follow the latest Upwork, Fiverr, and Etsy policies** for your category. This page is a seller self-check, **not** legal advice and **not** a “bypass review” guide.  
> 2. Do **not** treat this as instructions to evade moderation or list prohibited services.  
> 3. **Hard nos:** fake reviews / review trading / fake orders; homework or exam proxy work; counterfeits / IP theft; forged IDs or documents; unauthorized scraping, cracking, or security bypass.  
> 4. When unsure, delete the claim or rewrite as a **verifiable deliverable**. If still unsure, read official rules or don’t publish.

---

## 1. Five principles first

1. **Promise the file, not the outcome** — OK: “edited copy delivered.” Risky: “guaranteed approval / guaranteed hire / guaranteed viral.”  
2. **Boundaries, not “I do everything”** — OK: “presentation polish.” Risky: “any design under the sun.”  
3. **Truth only** — no invented sales counts, client names, team size, or credentials.  
4. **Legal use only** — unclear or illegal use → decline.  
5. **No gray-hat methods** — including review fraud paths, moderation loopholes, or forged materials.

---

## 2. Risky phrasing → safer rewrites (examples)

| Riskier (audit) | Why careful | Safer rewrite example |
|-----------------|-------------|------------------------|
| “Guaranteed approval / will 100% pass review” | Outcome isn’t yours alone | “I’ll revise layout/copy to your brief; approval follows their rules” |
| “Guaranteed hire / guaranteed win the bid” | Same | “Clearer structure & wording for you to submit” |
| “Cheapest on earth / best ever” | Absolute / misleading ads | “Quoted by time / transparent unit pricing” |
| “Official / insider channel / exclusive access” | False authority | Delete; state independent freelancer |
| “Buy reviews / fake reviews / review exchange” | Policy violation | **Don’t write it. Don’t do it.** |
| “Homework / exam / take my test” | Academic integrity + policy | **Decline**; state “no homework or exam work” |
| “Cracked software / license bypass / piracy” | IP + security | **Decline**; assist only within legitimate licenses |
| “Fake ID / forged stamp / doctored documents” | Illegal | **Forbidden** |
| Medical cure claims / investment return promises | Heavily regulated | Don’t claim; stay out of scope you can’t defend |
| “100% satisfaction, unlimited revisions” | Scope explosion + overpromise | “[N] rounds included; changes re-quoted” |
| Fake “XXXX orders completed” | Misrepresentation | Omit, or only state verifiable truth |
| Fake invoice category / tax tricks | Legal risk | Describe only what you can actually provide |

> Reminder table — **not** a full banned-word dictionary, and **not** a guarantee that a rewrite will pass review.

---

## 3. Fast checklist — title / description / chat

**Before publish**

- [ ] Absolute claims (best, #1, guaranteed, always) — delete if you can  
- [ ] Hints of fake reviews, cheating, or IP theft?  
- [ ] Invented cases, sales, or credentials?  
- [ ] Decline list covers homework/exams and illegal uses?  
- [ ] Price matches what you can deliver?

**In chat**

- [ ] Buyer asks for fake reviews → refuse and stop that thread  
- [ ] Buyer asks for homework/exam proxy → refuse  
- [ ] Buyer asks for forgery → refuse  
- [ ] Unclear use → ask for a legal purpose; if they won’t say, decline  

**Compliant decline snippet**

```text
That falls under work I don’t take (fake reviews / homework-exams / forgery / policy violations). I can’t do it or advise on it. If you have another compliant [SKILL] brief, I’m happy to look.
```

## 4. This kit never covers / you shouldn’t either

| Forbidden | Note |
|-----------|------|
| Fake reviews, fake orders, review trading | Policy risk; harms you long-term |
| Homework / exam proxy / answer selling | Policy + integrity |
| Tutorials on evading platform review | Not provided here — don’t invent one |
| Pasting a competitor’s listing wholesale | Duplicate / IP risk — rewrite from the skeleton |
| Guaranteeing impressions, inquiries, or sales | No template can promise that |

---

## 5. When rules change

1. Trust the in-app / help-center policy and enforcement notices.  
2. If a phrase cluster starts getting flagged: **shrink promises, clarify delivery, strengthen the decline list**.  
3. If this page conflicts with official rules, **official rules win** — stop using the conflicting line.

---

## 6. One-liner for the bottom of a gig

```text
This gig is for legal, policy-compliant skill work only. No fake reviews, no homework/exam proxy work, no forgery or IP theft. Platform rules may update; confirm a clear, lawful scope before ordering.
```
