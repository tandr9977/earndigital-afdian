# 04 · Pricing Tiers (how to write them + blank tables)

> First set your **pricing unit** and **floor**, then fill three tiers. Dollar amounts below are **placeholders for structure** — replace with yours. This is not universal pricing advice and does not guarantee sales.

---

## 1. Why three tiers

| Tier | Buyer mindset | What you must spell out |
|------|---------------|-------------------------|
| Basic | Tight budget, “good enough” | Narrower scope, fewer rounds, longer turnaround |
| Standard | Default for most people | Usual full scope, fair rounds, normal timing |
| Rush | Time-critical | Same Basic/Standard scope, compressed time + rush fee; often fewer rounds |

**Rule:** Extra money must buy something real (more delivery / less wait / more rounds). Don’t only change the price.

---

## 2. Tier write-ups (edit and reuse)

### Basic

```text
[BASIC · $___]
Includes: [1–2 core deliverables]
Revisions: [1] light round (typos / small tweaks)
Timing: [__] business days after scope lock
Excludes: [extra pages / style swap / from-scratch / multiple versions]
Best for: complete assets, simple asks, non-urgent
```

**Chat line:**  
“On a budget we can do Basic: only `[scope]`, 1 light round, `[timing]`, `$___`. For full `[item]`, upgrade to Standard.”

### Standard

```text
[STANDARD · $___] (most orders)
Includes: [usual full deliverable list]
Revisions: [2] rounds (one numbered list = one round)
Timing: [__] business days after scope lock
Add-ons: [source pack / extra sizes / short notes] +$___
Best for: clear use case + checkable acceptance criteria
```

**Chat line:**  
“For your brief I’d recommend Standard: `[list]`, 2 rounds, `[timing]`, `$___`. Confirm and I’ll schedule.”

### Rush

```text
[RUSH · add $___ or +__% on the matching tier]
Conditions: (1) lock scope now (2) send all assets now (3) feedback within [__] hours
Timing: first draft in [__] hours / [__] days (calendar-dependent — ask before ordering)
Revisions: ideally max [1–2] so we don’t miss the deadline
Not guaranteed: if the day is full I can’t jump the queue — ask “can you rush?” first
```

**Chat line:**  
“Rush possible — what’s the exact cutoff? If calendar allows: rush fee `$___` / +`__`%, rounds capped. Please send assets now.”

## 3. Pricing units by niche (for your blanks)

| Example niche | Suggested unit | What usually raises price |
|---------------|----------------|---------------------------|
| Small tools / scripts | Feature / hour | Rule complexity, edge cases, docs |
| Deck / presentation polish | Page / slide | Motion, chart rebuilds, template swap, extra slides |
| Copy polish | Word band / piece | Rewrite ratio, multiple tones, terminology checks |
| Retouch / simple design | Image / set | Detail level, cutout difficulty, multi-size, portrait consent notes |

## 5. Before you send a quote

- [ ] What’s included
- [ ] What’s excluded
- [ ] Revision rounds + change rules
- [ ] Timing (normal vs rush separated)
- [ ] Numbers you can live with — not impulse prices
- [ ] No “guaranteed outcome / unlimited revisions”
