## 2. Four category rewrites (change numbers to yours)

> Examples only. Delete anything you cannot deliver.

### 1) Small productivity tools / scripts

| Type | Example title | Bias |
|------|---------------|------|
| Outcome | Custom spreadsheet / office mini-tool \| Clear rules → I build \| Includes short usage notes | Convert |
| Situation | Tired of repeat clicks? \| Small script for batch sheets \| Confirm rules first | Reach+Convert |
| Delivery | Mini-tool \| Runnable files + brief README \| 2 revisions in price \| Scope changes re-quoted | Convert |
| Boundary | Personal tooling only \| No cracking, auth bypass, or unauthorized scraping \| Legal use only | Convert |
| Reach | spreadsheet automation batch tool script save time custom | Reach |

**Tip:** State inputs/outputs (“merge many sheets into one”). Never promise “universal scraper” or “bypass.”

### 2) Presentation / deck polish

| Type | Example title | Bias |
|------|---------------|------|
| Outcome | Presentation polish \| Fonts & colors unified \| Clearer structure \| You own content, I own layout | Convert |

| Boundary | Layout only \| No speechwriting \| No exam/cheating uses \| You supply licensed assets | Convert |
| Reach | PowerPoint polish layout branding pitch deck slides | Reach |

**Tip:** Page count + revision rounds beat vague “premium design” claims.

## 3. 30-second title self-check

- [ ] Skill name appears in the first ~15–20 characters / words platforms show
- [ ] One concrete deliverable (file type, rounds, format, or turnaround)
- [ ] No “guaranteed hire / #1 / fake reviews / exam help” vibes
- [ ] No invented years of experience, team size, or sales volume
- [ ] Prep 3 variants to rotate — don’t thrash the title ten times a day
